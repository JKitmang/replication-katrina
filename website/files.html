Browse the replication package

Every Stata .do file, the master script, and the documentation are listed on the left, grouped by role and tagged with the paper table each produces. Click any file to read it here — .do files are shown with line numbers, Stata syntax highlighting, and the documentation header parsed out; the Markdown docs are rendered in place.

Use the filter box to jump to a file by name, by what it does, or by table (try T5, quartile, instrument, or standardize). The raw text and a download link for each file are in the viewer header.

Note: this browser loads files from the package over the local server, so open it through the served URL (e.g. http://localhost:8745/website/files.html), not as a bare file.
