Abstract

Hurricanes Katrina and Rita displaced roughly 400,000 schoolchildren in 2005. Because evacuee families were placed by where buses, shelters, and relatives happened to be — not by school choice — the sudden arrival of evacuees into receiving schools provides quasi-random variation in peer composition.

The paper estimates how the share of evacuees in an incumbent ("native") student's school, grade, and classroom affects that student's test scores (math and reading), attendance, and disciplinary infractions — and, centrally, the structure of those peer effects (linear-in-means vs. monotonicity vs. invidious comparison vs. boutique/ability-grouping vs. "bad apple"). It finds strong support for monotonic, non-linear peer effects on achievement, rejects the linear-in-means and invidious-comparison models, and supports the "bad apple" model for behavior but not for test scores.

Research design

Identification is a difference-in-differences / value-added specification: incumbent outcome on the evacuee share, with school fixed effects, grade effects, year effects, grade×year interactions, demographic controls, and (published version) lagged pre-Katrina achievement. The evacuee share is 0 in every pre-2005-06 year, so identification comes from the change in incumbent outcomes in high- vs. low-evacuee schools after the storms.

The instrument (Houston only)Evacuees re-sorted across schools through the fall of 2005, so the late-October share is endogenous to school quality. The paper instruments it with the September 13, 2005 evacuee share — two weeks after landfall, excluding students still in the Astrodome/Reliant/George R. Brown mega-shelters, who almost all relocated within two weeks.

For the structure of peer effects, incumbents and evacuees are sorted into pre-Katrina achievement quartiles; the evacuee share is split by the quartile evacuees fall in and interacted with the incumbent's own quartile, producing a 4×4 coefficient matrix whose pattern discriminates between competing peer-effect models.

Software & dependencies

Developed under Stata 11/12; runs in any modern Stata. Three user-written (SSC) commands are required:

ssc install outreg2     // exports regression results to the result tables
ssc install quantiles   // sorts observations into quartile / quintile groups
ssc install renames     // batch variable renaming (taks_append.do)

Everything else — areg, ivreg, ivreg2, xtreg, xi, test, lincom, suest, collapse, reshape — is official Stata. See PROGRAMS_AND_COMMANDS.md for the eight reusable code idioms the package is built from.

merge_c.do is the analytic core: it standardizes TAKS scores within grade×year, builds the evacuee shares (campus / grade / class), constructs the Sept-13-2005 instrument, imputes time-invariant traits (with flags), and restricts to students enrolled in 2005-06 — the only year evacuee status is observed.

How to run

  1. Open master.do and edit the four global path lines.
  2. Install the three SSC commands above.
  3. Obtain and stage the data under $raw / $work.
  4. Repoint the hardcoded absolute paths inside the .do files (see new-years §, step 2).
  5. Un-comment the do lines in order: A (LA cleaning) → B (Houston cleaning) → C (dataset construction) → D/E (analysis by table).
Run order is load-bearingmerge_c.do consumes the outputs of the four Houston cleaning files; the analysis files consume merge_c.do, quartile_data.do, and the LA standardization outputs. Running an analysis file before its inputs exist fails on a missing .dta.

Re-running with new years

The chief obstacle to extending the code is that years are hardcoded throughout — in loops, sample filters, the standardization constants, the instrument, and the "carry 2005 forward to 2006" rules. Each annotated .do file flags its own with a // YEAR HARDCODE comment. The checklist:

  1. Stage new raw data in the same shape — match variable names and the per-year file naming the loaders expect (ada-2007-08, demog_2007, taks_2007_eng_a, …).
  2. Repoint hardcoded paths — find/replace each absolute root (/work/i/imberman/imberman/…, /home/s/simberman/…, C:\D\Research\…) with your global.
  3. Widen every year range — forvalues year=1997/2006, keep if year>=2002, etc. Keep 2005 as the treatment onset (share = 0 before it) unless re-anchoring the design.
  4. Rebuild standardization — extend the within-grade×year summarize loops; for Houston's hardcoded statewide TAKS mean/SD constants you must supply each new year's official figures or switch to the data-driven loop.
  5. Extend baseline quartiles — revisit the "blank thin grade/year cells" rules so new tested grades are handled correctly.
  6. Extend grade×year fixed effects — these expand automatically, but check any hand-named/omitted base-category dummy.
  7. Re-run & reconcile — reproduce the original years first (diff against the published tables), then add new years so divergences are attributable to the new data, and re-check the placebo / pre-trend files.
Conceptual caveatThe design is anchored to a one-time 2005-06 shock. Adding later years extends the post-period (persistence, dynamics); it does not create new treatment. To study a different shock, treat the year the new transfers arrive as the new "2005-06" and shift every year reference accordingly.
